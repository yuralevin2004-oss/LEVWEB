Everest Ultimate Edition — эксперименты

Пять экспериментов: тест диска, стресс-тест, тесты CPU , тест памяти и создание отчёта.

Эксперимент 1. Тест диска (Disk Benchmark)

Отдельный инструмент для оценки производительности накопителя. Позволяет измерить случайное чтение/запись, среднюю и минимально/максимальную скорость, а также загрузку CPU при работе с диском.

Вызов: Сервис → Тест диска.
График случайного чтения: текущая, минимум/максимум и средняя скорость, загрузка CPU и размер блока.

Эксперимент 2. Стресс‑тест (System Stability Test)

Отдельный модуль, создающий длительную нагрузку на CPU/FPU/кэш/память с графиками температуры/загрузки.

Вызов System Stability Test.
Процесс теста: 100% загрузка CPU и графики температур.

Эксперимент 3. Тесты CPU/FPU

Синтетические тесты CPU Queen, PhotoWorx, Zlib, AES, FPU Julia/Mandel измеряют вычислительную производительность.

Панель выбора CPU/FPU тестов.
Сводная таблица результатов для сравнения.

Эксперимент 4. Тест памяти

Измеряет пропускную способность и задержку памяти: Read/Write/Copy, Latency, кеши L1/L2/L3.

Окно Cache & Memory Benchmark.

Эксперимент 5. Мастер отчётов (Report Wizard)

Формирует документ с конфигурацией/ПО/результатами. Это не бенчмарк и не стресс‑тест, а отдельный режим.

Стартовое окно мастера.
Выбор профиля: все/аппаратные/программные/тестовые/пользовательский.
Просмотр итогового отчёта.
